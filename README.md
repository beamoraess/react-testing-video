# React Testing Library & Jest - Estudos 🧪

Este repositório contém exemplos, exercícios e boas práticas para testar aplicações React utilizando **React Testing Library** e **Jest**.

## 📌 Objetivos
- Compreender os conceitos fundamentais de testes em aplicações React.
- Aprender a escrever testes unitários e de integração.
- Explorar boas práticas para testes mais confiáveis e eficientes.
- Automatizar testes e integrar com CI/CD.

## 🛠 Tecnologias Utilizadas
- [React](https://react.dev/)
- [Jest](https://jestjs.io/)
- [React Testing Library](https://testing-library.com/docs/react-testing-library/intro/)
- [Vitest](https://vitest.dev/) (Opcional, alternativa ao Jest)

## 🤔 O que são testes?
Testes são uma forma de garantir que o funcionamento do nosso código está correto.

Como eles são automatizados, conseguimos testar vários cenários com apenas um comando.

## 🧪 Tipos de testes
- **Testes Unitários** → Testamos um componente ou unidade de código isoladamente, sem chamar agentes externos, como APIs. Se necessário, utilizamos mocks.
- **Testes de Integração** → Testamos dois ou mais componentes trabalhando juntos, simulando interações entre eles. Também utilizamos mocks para agentes externos.
- **Testes End-to-End (E2E)** → Testes maiores e mais robustos que simulam o comportamento do usuário em toda a aplicação. Uma ferramenta popular para E2E é o **Cypress**.

## ✍️ Como escrever esses testes?
- **Jest** → Testa aplicações JavaScript.
- **React Testing Library** → Fornece ferramentas para testar componentes React de forma acessível e confiável.

## 🎯 Por que aprender testes?
- Construir aplicações escaláveis e robustas.
- Garantir que a aplicação funcione corretamente em vários cenários.
- Facilitar refatorações sem medo de quebrar funcionalidades.
- Melhorar a qualidade e manutenção do código.
